# Tech City — ISP কাস্টমার অ্যাপ + ইন-অ্যাপ অ্যাডমিন প্যানেল

একটাই Flutter অ্যাপ। `fahadtaukir4@gmail.com` দিয়ে লগইন করলে অ্যাডমিন প্যানেল খোলে, বাকি সবাই কাস্টমার অ্যাপ দেখে।
আলাদা কোনো ওয়েব প্যানেল বা সার্ভার লাগে না। ডেটা থাকে Firebase এ (Spark/ফ্রি প্ল্যানে চলবে)।

## ১. Firebase সেটআপ (একবার)

1. https://console.firebase.google.com এ নতুন প্রজেক্ট বানান।
2. **Authentication → Sign-in method → Email/Password** চালু করুন।
3. **Firestore Database → Create database** (production mode, লোকেশন: asia-south1 বা asia-southeast1)।
4. Firestore → **Rules** ট্যাবে `firestore.rules` ফাইলের পুরো লেখা পেস্ট করে **Publish** করুন।
5. প্রজেক্টে একটা Android অ্যাপ যোগ করুন (package name হবে আপনার Flutter প্রজেক্টের, যেমন `com.example.tech_city`)।

## ২. Flutter প্রজেক্ট

```
flutter create tech_city
cd tech_city
flutter pub add firebase_core firebase_auth cloud_firestore url_launcher
```

এই জিপের `lib/` ফোল্ডারের ৫টা ফাইল (`main.dart`, `common.dart`, `auth.dart`, `user_screens.dart`, `admin_screens.dart`) প্রজেক্টের `lib/` এ কপি করুন (পুরনো `main.dart` রিপ্লেস হবে)।

Firebase কানেক্ট করতে হয় দুইভাবে, যেকোনো একটা:

- **সহজ:** `dart pub global activate flutterfire_cli` তারপর `flutterfire configure`
- **হাতে:** Firebase console থেকে `google-services.json` নামিয়ে `android/app/` এ রাখুন, আর Firebase এর নির্দেশ মতো google-services gradle plugin যোগ করুন।

তারপর `flutter run`। রিলিজ APK: `flutter build apk --release`

যদি বিল্ডে `minSdkVersion` নিয়ে এরর আসে, `android/app/build.gradle` (বা `.kts`) এ `minSdk = 23` করে দিন।

## ৩. অ্যাডমিন অ্যাকাউন্ট চালু করা

1. অ্যাপ খুলে **নতুন অ্যাকাউন্ট খুলুন** চাপুন।
2. ইমেইল: `fahadtaukir4@gmail.com`, একটা পাসওয়ার্ড দিন (বাকি ঘরগুলো যা খুশি দিন, অ্যাডমিনের জন্য সেগুলো সেভ হয় না)।
3. এরপর থেকে এই ইমেইল/পাসওয়ার্ডে লগইন করলেই অ্যাডমিন প্যানেল খুলবে।

**জরুরি:** অন্য কেউ আগেই এই ইমেইল দিয়ে অ্যাকাউন্ট খুলে ফেলার আগে নিজে সবার আগে এটা করে নিন।

## ৪. প্রথমবার অ্যাডমিন প্যানেলে যা করবেন

1. **সেটিংস:** জোন/সাব-এরিয়া লিস্ট, প্যাকেজ লিস্ট, পয়েন্ট রেট (১০ পয়েন্ট = ১ টাকা), প্রতি রেফারেলে কত পয়েন্ট, সাপোর্ট নম্বর দিন।
2. **ব্যানার:** অফার/নোটিস লিখে যোগ করুন (শুধু লেখা, ছবি নেই)। রং বাছুন, চাইলে মেয়াদ দিন।
3. **লিডারবোর্ড ও গিফট:** মাস বেছে র‍্যাঙ্ক ১–১০ এর গিফট লিখে সেভ করুন। মাস শেষে **Finalize & Award** চাপলে Top 10 ফাইনাল হয় ও বিজয়ীরা নোটিফিকেশন পায়।

## ৫. কাজ কীভাবে চলে

| বিষয় | নিয়ম |
|---|---|
| রেফারেল | নতুন ইউজার সাইন আপে কোড দিলে অ্যাডমিনের **রেফারেল কনফার্ম** লিস্টে "অপেক্ষমাণ" হয়ে আসে। কানেকশন চালু ও প্রথম বিল হলে আপনি **কনফার্ম** চাপবেন, তখনই রেফারকারী পয়েন্ট পাবে ও লিডারবোর্ডে ১ গোনা হবে |
| রিডিম | ইউজার পয়েন্ট দিলে সাথে সাথে পয়েন্ট কাটে, রিকোয়েস্ট আপনার কাছে আসে। আপনি বিলে ছাড় দিয়ে **ছাড় দেওয়া হয়েছে** চাপবেন। বাতিল করলে পয়েন্ট ফেরত যায় |
| কমপ্লেইন | ইউজার জমা দিলে টিকেট নম্বর পায় (Processing)। আপনি টেকনিশিয়ান নাম/ফোন দিলে ইউজার সেটা দেখে (Technician Assigned), শেষে **সমাধান হয়েছে** |
| শিফট / প্যাকেজ | ইউজার আবেদন করে। শিফটে আপনি ফি ঠিক করে অনুমোদন দেন। প্যাকেজ অনুমোদন দিলেই ইউজারের প্যাকেজ নিজে থেকে বদলে যায় |
| নোটিফিকেশন | সব এলাকা বা নির্দিষ্ট জোন বেছে পাঠান |

## ৬. সীমাবদ্ধতা (জেনে রাখুন)

- **নোটিফিকেশন ইন-অ্যাপ:** অ্যাপের নোটিফিকেশন ট্যাবে আসে, ব্যাজ দেখায়। অ্যাপ বন্ধ থাকলে ফোনের স্ট্যাটাস বারে পুশ যায় না। সেটা করতে Firebase Cloud Functions লাগবে, যা Blaze (কার্ড লাগে) প্ল্যান চায়। পরে চাইলে যোগ করা যাবে।
- **ইমেইল ভেরিফিকেশন নেই:** অ্যাডমিন চেনা হয় ইমেইল দিয়ে, তাই ধাপ ৩ আগে করে নিন।
- **বিলিং সফটওয়্যার যুক্ত নয়:** ছাড় আপনি হাতে দেন।
- **পয়েন্ট নিরাপত্তা:** ইউজার শুধু নিজের পয়েন্ট *কমাতে* পারে (রিডিমের জন্য), বাড়াতে পারে না। পয়েন্ট বাড়ে শুধু অ্যাডমিন কনফার্ম করলে।
- অ্যাপের ভাষা বাংলা। নাম `common.dart` এর `kAppName` এ বদলান।

## ৭. নতুন ফিচার (v2) — অ্যাডমিন প্যানেলে কোথায় কী

| ফিচার | অ্যাডমিন প্যানেলে |
|---|---|
| আউটেজ / মেইনটেন্যান্স অ্যালার্ট | **আউটেজ অ্যালার্ট** — এলাকা বেছে মেসেজ লিখুন, ঠিক হলে সুইচ বন্ধ করুন। ওই এলাকার ইউজারদের হোম স্ক্রিনে লাল ব্যানার আসে |
| FTP / TV / BDIX শর্টকাট | **FTP / TV শর্টকাট** — নাম, লিংক, আইকন, ক্রম |
| টেকনিশিয়ান রেটিং | **টেকনিশিয়ান রেটিং** — গড় স্কোর, টেকনিশিয়ান অনুযায়ী, ফিডব্যাক |
| NPS সার্ভে | **NPS সার্ভে** (মাস অনুযায়ী) + সেটিংসে প্রশ্ন/চালু-বন্ধ |
| বিল রিমাইন্ডার | **সেটিংস** এ বিলের তারিখ; **ইউজার লিস্ট** এ ইউজার ধরে আলাদা তারিখ ও "এই মাসের বিল পরিশোধিত" |
| Check My Line | **সেটিংস** এ টেস্ট সার্ভার IP/পোর্ট ও সমাধানের ধাপ |

**বিল রিমাইন্ডার:** বিলের ৩ দিন আগে থেকে তারিখ পর্যন্ত ইউজারের হোম স্ক্রিনে দেখায়। বিল পেলে ইউজার লিস্টে গিয়ে "এই মাসের বিল পরিশোধিত" চালু করে দিন, তাহলে ওই ইউজারের রিমাইন্ডার বন্ধ হবে।

**Check My Line:** ফোনের ইন্টারনেট, (সেটিংসে দিলে) আপনার লোকাল সার্ভারে পৌঁছানো ও সাড়ার সময়, আর এলাকায় আউটেজ আছে কিনা দেখে। এটা রাউটারের ভেতরের অবস্থা দেখতে পারে না।

**নতুন ফিচার চালু করতে:** Firestore Rules আবার পেস্ট করে Publish করতে হবে।
